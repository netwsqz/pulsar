# 03 — 发现页重做为个人化聚合首页

**What to build:** 发现页变成一屏聚合的个人化首页——最近播放、最常播放、最近添加、每日推荐、随机专辑等多个 section，用 Auxio 的布局语言呈现，保留 Pulsar 的封面取色与玻璃材质。

**注意：这一页在 Auxio 里没有参照**（Auxio 的 Home 就是曲库列表本身），属自创设计。开工前建议先岔一次 `/prototype` 定风格，再落地。

**Blocked by:** 01（设计 token 底座）、02（播放历史数据层）
