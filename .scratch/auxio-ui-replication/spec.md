# Spec：复刻 Auxio 界面（发现页 + QQ 下载页 + 库页替换）

## Problem Statement

Pulsar 现在的界面是自研的一套 Material3 + 玻璃岛风格，发现页只有「每日推荐 + 随机专辑」两块，库页（全部音乐 / 专辑 / 播放列表）是纯列表。用户希望参考开源播放器 Auxio 的界面与布局结构，把 Pulsar 的视觉和排版提升到 Auxio 那种克制、成熟的水准，同时保留 Pulsar 自己的美学身份（玻璃岛、封面取色、品牌配色）。

Auxio 本身无法直接搬运（详见 ADR-0004）：它是 View/XML 架构、许可 GPL-3.0，所以这是一次**照设计规格用 Compose 重写**的改造，不是代码移植。

## Solution

以「Auxio 骨架 + Pulsar 皮肤」为总原则，分三块交付：

1. **建立全局设计 token 底座**——把 Auxio 的尺寸/圆角/触摸目标量纲抽成一套 Compose `Dimens`，全局替换散落的硬编码 dp。这是所有页面保持一致视觉的前提。
2. **发现页重做为个人化聚合首页**——最近播放、最常播放、最近添加、每日推荐、随机专辑等 section 一屏聚合。注意：**这一页在 Auxio 里没有参照**（Auxio 的 Home 就是曲库列表），属自创设计。
3. **库页替换 + QQ 下载页重构**——顶层导航对齐 Auxio 的 5 个 tab（Songs / Albums / Artists / Genres / Playlists），全部音乐/专辑/播放列表页换成 Auxio 布局语言；新增艺术家/流派两个维度；QQ 下载页按 Auxio 的列表/卡片语言重排。

**本次只做界面与布局结构，不复刻 Auxio 的操作逻辑**（长按多选、拖拽排序、tab 可配置等），播放界面（miniplayer + 全屏播放页）也不动。

## User Stories

### 设计 token 底座

1. 作为开发者，我想要一套统一的间距/圆角/触摸目标常量，这样各页面不再散落魔法数字、视觉自动一致。
2. 作为用户，我想要所有页面看起来出自同一个设计系统，这样切换页面时不会有拼接感。
3. 作为开发者，我想要新增页面时直接取用设计 token，这样不用每次重新决定间距。

### 导航

4. 作为用户，我想要顶部导航能在一排可横滑的入口间切换，这样能快速到达想看的维度。
5. 作为用户，我想要导航保留玻璃岛的视觉样式，这样 App 仍然一眼可辨是 Pulsar。
6. 作为用户，我想要顶层入口是 Songs / Albums / Artists / Genres / Playlists 五类，这样能按不同维度浏览曲库。
7. 作为用户，我想要发现页作为其中一个顶层入口，这样个人化推荐和曲库浏览都能到达。
8. 作为用户，我想要导航选中态清晰可见，这样随时知道自己在哪一页。

### 发现页（自创聚合）

9. 作为用户，我想要打开 App 第一眼看到「最近播放」，这样能接着上次听的继续。
10. 作为用户，我想要看到「最常播放」，这样能快速回到我喜欢的歌。
11. 作为用户，我想要看到「最近添加」，这样能发现曲库里的新内容。
12. 作为用户，我想要保留「每日推荐」，这样每天有新鲜的本地选曲。
13. 作为用户，我想要保留「随机专辑」封面墙，这样能随机逛专辑。
14. 作为用户，我想要下拉刷新能换一批推荐，这样不满意时可以重来。
15. 作为用户，我想要各 section 的内容以卡片/横滑形式呈现，这样一屏能看到多个维度。
16. 作为用户，我想要在未登录或加载中看到骨架占位，这样知道内容正在来。
17. 作为用户，我想要在无数据时看到明确的空态文案，这样不会以为 App 坏了。
18. 作为用户，我想要点击发现页的曲目直接播放，这样不用绕路。
19. 作为用户，我想要点击发现页的专辑进入专辑详情，这样能看整张专辑。

### 库页（Auxio 布局语言）

20. 作为用户，我想要 Songs 页按 Auxio 的列表项样式显示曲目（封面 + 歌名 + 副信息 + 更多按钮），这样浏览体验和 Auxio 一致。
21. 作为用户，我想要 Albums 页以封面网格/横滑形式显示专辑，这样视觉上更像 Auxio。
22. 作为用户，我想要 Playlists 页按 Auxio 的列表语言显示，这样和库页风格统一。
23. 作为用户，我想要 Artists 页列出所有艺术家，这样能按艺术家浏览。
24. 作为用户，我想要 Genres 页列出所有流派，这样能按流派浏览。
25. 作为用户，我想要点击艺术家/流派能看到其下的专辑或曲目，这样能深入浏览。
26. 作为用户，我想要库页在加载时显示骨架，这样界面不闪白。
27. 作为用户，我想要库页在请求失败时显示错误与重试，这样网络问题可恢复。
28. 作为用户，我想要曲目列表项保留现有的"加入队列"入口，这样原有操作不丢。

### QQ 下载页

29. 作为用户，我想要 QQ 下载页的搜索框、结果列表、任务列表按 Auxio 的列表/卡片语言重排，这样它和新的库页视觉一致。
30. 作为用户，我想要搜索歌曲/专辑的结果行沿用 Auxio 的列表项结构，这样浏览一致。
31. 作为用户，我想要下载任务以清晰的进度行呈现，这样知道下载到哪了。
32. 作为用户，我想要未连接服务时的提示卡与 Auxio 风格对齐，这样不是突兀的一块旧样式。
33. 作为用户，我想要凭证过期横幅、文件密钥卡、服务状态卡保持功能不变只换视觉，这样功能不回归。

### 视觉与主题

34. 作为用户，我想要播放时界面能随专辑封面取色，这样保留 Pulsar 的特色。
35. 作为用户，我想要字体沿用 Pulsar 现有的 Righteous + Poppins，这样品牌一致。
36. 作为用户，我想要排版借鉴 Auxio 的紧凑负字距，这样更精致。
37. 作为用户，我想要明暗两套主题都正常，这样夜间使用不刺眼。
38. 作为用户，我想要列表项圆角/间距与 Auxio 量纲一致，这样"神似"。
39. 作为用户，我想要专属页（搜索/设置/已缓存/QQ下载）自动继承新视觉底座，这样全 App 不跳。

### 主题色板（ADR-0005）

45. 作为用户，我想要整个 App 的配色（按钮、chip、卡片、滑块、文字色阶）跟着当前专辑走，这样沉浸感不只是背景一条渐变。
46. 作为用户，我想要没在播歌、或封面是黑白/无封面时，界面回落到一套稳妥的默认配色，这样不会突然变成灰色或残留上一首的颜色。
47. 作为用户，我想要自己挑一套配色作为兜底，这样我可以在没有封面色时也看到喜欢的颜色。
48. 作为用户，我想要设置页能看清当前生效的是「封面」「手动」还是「默认」，这样不会以为设置没生效。
49. 作为用户，我想要切歌时配色平滑过渡，这样不会闪。
50. 作为用户，我想要全屏播放页保持它现在的沉浸背景，但控件和玻璃跟着新配色走，这样两处不割裂。
51. 作为用户，我想要系统状态栏/导航栏融入界面，这样不是一条突兀的色带。

### 数据

40. 作为用户，我想要「最近播放」显示服务端的真实播放历史，这样换设备也一致。
41. 作为用户，我想要「最常播放」按服务端播放次数排序，这样是我真实的口味。
42. 作为用户，我想要艺术家/流派列表由现有专辑数据聚合而来，这样不需要额外请求。
43. 作为用户，我想要播放历史请求失败时发现页优雅降级（其余 section 照常显示），这样局部失败不拖垮整页。
44. 作为用户，我想要切换账号时这些新数据一起清空，这样不残留上个账号的内容。

## Implementation Decisions

### 模块与接口

- **数据层**：`JellyfinApi` / `JellyfinDataSource` 新增方法——最近播放、最常播放、艺术家列表、流派列表、按艺术家取专辑、按流派取专辑。全部返回 `Result<T>`，错误映射沿用现有 `JellyfinError`。
- **DTO 层**：新增艺术家、流派的 DTO 与 `toXxx()` 转换，`@SerialName` 映射 Jellyfin 大写字段。
- **ViewModel 层**：`JellyfinViewModel` 新增对应的 `loadRecentlyPlayed()` / `loadFrequent()` / `loadArtists()` / `loadGenres()`，沿用现有「字段非空即已加载」幂等模式 + generation 防过期。`JellyfinUiState` 新增对应字段。
- **纯函数层**：新增一个客户端分组模块（仿现有 `DiscoverPicks`），把已加载的专辑列表按 artist / genre 聚合成艺术家、流派分组。**零新 API**。
- **UI 层**：新增 `Dimens`（设计 token）；发现页重写；库页按 Auxio 布局语言重写；QQ 下载页重排；导航壳改造为 Auxio tab 语义。

### 关键决策（来自 grill 会话）

- **Q1 复刻深度**：视觉 + 布局结构，不抄操作逻辑。
- **Q3 融合方向**：Auxio 骨架 + Pulsar 皮肤。
- **Q8/Q15 导航**：玻璃岛**仍是导航载体**，承担 Auxio TabLayout 的角色，行为/语义照 Auxio 调。
- **Q10 主题**：保留封面取色。
- **Q11 操作逻辑**：本次砍掉（长按多选、拖拽排序、tab 可配置全部不做）。
- **Q12 一致性**：建立全局设计 token 底座，专属页自动继承。
- **Q13 替换方式**：删旧换新，不做新旧并存。
- **Q16/Q19 顶层 tab**：对齐 Auxio 5 个（Songs/Albums/Artists/Genres/Playlists）+ 发现页。
- **Q17 历史数据**：走 Jellyfin 服务端查询（`SortBy=DatePlayed` / `PlayCount` / `DateCreated`），非本地存储。
- **Q18 发现页**：个人化聚合，**自创**，Auxio 无参照。
- **Q20 代码来源**：只取设计规格，不碰 GPL 源码（ADR-0004）。
- **Q21 Artists/Genres**：客户端分组已有数据，零新 API。

### 设计量纲（取自 Auxio，见 `research-auxio.md`）

- 间距：4 / 8 / 12 / 16 / 20 / 24 dp
- 触摸目标：48 / 56 / 64 dp
- 圆角：16 / 20 dp（BottomSheet 特调 20）
- 排版：借鉴负 letterSpacing 让标题更紧凑
- 字体：**保留 Pulsar 的 Righteous + Poppins**，不换 Inter

### 主题色板（ADR-0005）

- **种子色优先级**：当前播放曲目的封面鲜艳色（vibrant）→ 用户自选预设色 → 品牌靛蓝默认色板。
- **推导算法**：手写，扩展现有 `CoverPalette.kt` 的 HSL 工具（`hslOf` / `hslColor`），按 Material3 角色明度档位生成整套色板。**不引入新依赖。**
- **色源统一**：种子、强调色、全屏播放页兜底渐变取同一个种子，避免切页面跳色。`vibrantSwatch` 为 null 时回退到现有 `selectCoverSwatch`，再回退默认色板。
- **背景归属**：主界面背景由色板决定（中性 tinted surface）；全屏播放页背景仍由封面决定（渐变 + 模糊 + scrim），文字恒白，系统栏图标恒亮。
- **对比度**：`on*` 角色由明度档位结构保证，不做逐对事后校验。
- **过渡**：实际被用到的十来个角色 800ms 同步动画，与现有背景渐变一致。
- **预设色**：设置页「外观」一节，16 个（Auxio 强调色集合去掉 Dynamic），存 ARGB 而非序号。
- **存储**：`ThemePreferences` 挂现有共享 `pulsarPreferencesDataStore`，与 `LoudnessPreferences` 同一套路。
- **系统栏**：透明 + edge-to-edge；全屏播放页强制亮色图标，退出恢复。

## Testing Decisions

**测试哲学**：只测外部行为，不测实现细节。手写 Fake 优先（不用 Mockito/MockK），沿用项目现有约定。

**三个测试接缝（全部复用现有接缝，不新增框架）**：

1. **数据层接缝**（已有）：新增的播放历史/艺术家/流派查询方法，用 `JellyfinDataSourceTest` + Ktor `MockEngine` 验证请求参数正确（`SortBy=DatePlayed` 等）与 DTO 映射。先例：现有 `JellyfinDataSourceTest`。
2. **ViewModel 接缝**（已有）：新增的 `loadXxx()`，用 `JellyfinViewModelTest` + `FakeJellyfinApi` 验证幂等加载、generation 防过期、失败降级、会话切换清空。先例：现有 `JellyfinViewModelTest`。
3. **纯函数接缝**（新增，仿 `DiscoverPicks`）：客户端艺术家/流派分组，做纯函数单测——无 IO、稳定排序、边界用例（空列表、缺失 artist/genre 字段、同名归并）。先例：`DiscoverPicksTest`。
4. **色板推导接缝**（新增，仿 `CoverPaletteTest`）：种子色 → `ColorScheme` 的推导是纯函数，单测覆盖——色相保留、明度档位单调、`on*` 角色对比度结构、vibrant 为空时回退链、浅/深两套都成立。先例：`CoverPaletteTest`（`app/src/test/java/com/example/pulsar/ui/theme/`）。

**不测的部分**：设计 token（纯常量，YAGNI）；Compose 布局（本项目 UI 一向真机肉眼验证，无 Compose UI 测试框架）；系统栏图标明暗（需要真实窗口，真机验收）。

## Out of Scope

- **播放界面**（miniplayer + `NowPlayingScreen`）——本次不碰（Q4）。
- **操作逻辑复刻**——长按多选、拖拽排序、tab 可配置、M3U 导入导出，全部不做（Q11）。
- **Auxio 的 MediaStore 相关逻辑**——本地扫描、索引进度、文件夹选择、存储权限，全丢（Jellyfin 无此概念）。
- **艺术家/流派详情页的深度功能**——只做「点进去看其下专辑/曲目」，不做 Auxio 的完整详情页功能集。
- 不改任何数据层已有的接口行为（只新增）。

> **已被 ADR-0005 推翻的条目**：原 Out of Scope 写着「17 个强调色 + 动态取色——不引入，Pulsar 保留自有配色 + 封面取色」。现在**主题色板本身由封面推导**，并允许用户自选兜底预设色。见下方「主题色板」一节。
