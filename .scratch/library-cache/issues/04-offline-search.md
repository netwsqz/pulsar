# 04 — 离线搜索 + 「需要联网」提示

**What to build:** 断网时搜索框照常能用（在本地快照里搜），并且界面明说这是「离线搜索」；播放列表那一屏明说「需要联网」。做完这一票，断网时不会撞上莫名其妙的报错。

**Blocked by:** 02 — 曲库快照

**Status:** ready-for-human（代码完成）

- [x] 断网时搜索改为在曲库快照里过滤（歌名 / 歌手 / 专辑）
- [x] 搜索框附近标明**「离线搜索」**，让用户知道搜的范围变小了（在线搜是由 Jellyfin 搜的，更宽）
- [ ] 离线搜索结果里：缓存过的正常放、没缓存的照样标灰（跟工单 03 一套）
- [x] 断网时点**播放列表**那一屏 → 明说「需要联网」，不转圈、不崩、不显示空白
- [x] **不要**为了这一屏去提前拉所有播放列表存起来（规格「明确不做」）
- [ ] 恢复联网后搜索自动回到服务端搜索（不用手动切，不用重启 App）
- [x] 保留已有的 300ms 防抖，别因为换成本地过滤就把它拆了
- [x] 测试：过滤纯函数；ViewModel 层断言在线走服务端、离线走本地快照
