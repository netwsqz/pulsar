# 06 — 缓存清理口径

**What to build:** 缓存不能只增不减地攒着一堆已经没用的东西。删歌时副本跟着走；退出登录时清空，但登录过期不清。

**Blocked by:** 01 — 音频缓存落地

**Status:** ready-for-human（代码完成）

- [x] 在 App 里删掉一首歌（走 ADR-0001 的 PC 伴生服务那条路）**成功后**，顺手删掉这首的本地副本
- [x] **改名不动缓存**——改名改的是内嵌标签，歌没变，副本照样能放。**加一条测试钉死**，免得以后有人「顺手」也把它清了
- [x] 主动**退出登录** → 清空缓存 + 快照
- [x] 只是 **token 过期**（会话失效）→ **不清**（**铁律 5**）
- [x] 删副本失败（文件被占 / 目录没了 / 缓存层报错）**不能让删歌这个操作显示失败**——删歌成功就是成功（**铁律 1**）
- [x] 退出登录清空缓存时，如果缓存层报错，**不能挡住退出登录**本身
- [x] 测试：ViewModel 层断言「删歌成功 → 副本被删」「退出登录 → `clearCache` 被调用」「会话过期 → **没有被调用**」

## Comments

**实现记录（2026-09-25，agent）：**

- 删歌（单删/批量删）成功后 `removeCachedCopy` fire-and-forget 删副本，失败静默（铁律 1）。
- 退出登录：`signOut` 里清缓存+快照，两个 clear 实现都吞异常，不会挡退出。
- token 过期（`expireSession`）完全不碰缓存与快照，测试钉死（「会话过期不清缓存也不清快照」）。
- 「改名不动缓存」有专门测试钉死（`改名成功不动缓存`）。
