# 规格：曲库文件管理（删除 / 改名）

**Status:** ready-for-agent

## 问题陈述

歌是从 App 里搜、从 App 里下、在 App 里听的，但**想删一首、想改个名，必须走到电脑前开资源管理器**。链路是断的。

具体疼在哪：

- 下完一听不喜欢，想删——得开电脑，在 596 个文件里找到那一个，删掉。下次再遇到同样的歌，App 还会说"库里没有"（因为索引 3 分钟才重扫一遍）。
- 下载器写的标签是 QQ 那边的元数据，经常有错别字、多个空格、`.feat` 写法五花八门。想修——同样得开电脑、找文件、开标签编辑器。
- 曲库里已知有约 6 组重复（同曲不同格式、同曲散落两张专辑），清理全靠手工。

## 解决方案

**PC 伴生服务扩一组文件操作接口**（ADR-0001：不用 Jellyfin API，它做不到「移回收站」和「真改标签」）。**App 用长按菜单接入**。

四个操作，全部**可逆**：

| App 里叫 | 服务端真干的 |
|---|---|
| 删除 | 把文件挪到 `E:\file\Te_Music_deleted\`，保持原相对路径 |
| 改名 | 用 `mutagen` 写文件**内嵌标签**（歌名 / 歌手 / 专辑） |
| 恢复 | 从回收站挪回原处 |
| 清空回收站 | 真删（**只有这一个不可逆**，单独二次确认） |

## 三条铁律

**1. 只碰曲库里的文件。** 所有路径先 resolve 再校验 `LIBRARY_ROOT` 在不在它的父级里，跟 `qqmusic_service._parse_final_path` 同一个套路。回收站的路径同理，不许越界到别处。

**2. 只删「没有别的东西」的目录。** 删完一首歌后，如果专辑目录里只剩 Jellyfin 生成的 `.nfo`，把 `.nfo` 也挪进回收站、目录删掉（否则 Jellyfin 里会留一个点进去没歌的空专辑）。**只要目录里还有任何一个非 `.nfo` 文件，整个目录原样不动**——宁可留个空壳。

**3. 正在播的那首不许删。** 菜单里直接置灰。正在播时删文件，播放器那边文件没了但缓冲还在，是诡异 bug 的高发区。

## 用户故事

### 删除

1. 作为使用者，我想长按一首歌就把它删掉，不用走到电脑前。
2. 作为使用者，我想删之前有个确认框，手滑点了不会真出事。
3. 作为使用者，我想删完之后这首歌从列表里**立刻**消失，不用手动刷新。
4. 作为使用者，我想正在播的那首删不掉（菜单里是灰的），而不是删完 App 抽风。
5. 作为使用者，我想删掉一首在播放队列里还没播的歌时，它同时从队列里消失——不然播到那首才发现文件没了。
6. 作为使用者，我想刚删完就能重新下载同一首歌，不要被"已在库"挡下来（索引必须立刻更新）。

### 改名

7. 作为使用者，我想长按一首歌改它的名字，不用开电脑。
8. 作为使用者，我想一次能改歌名、歌手、专辑三个字段，而不是只能改一个。
9. 作为使用者，我想改完之后 App 里立刻显示新名字。
10. 作为使用者，我想改完之后**重启 App 还是新名字**（改的是文件里的标签，不是临时状态）。
11. 作为使用者，我想改错了能改回来。

### 批量

12. 作为使用者，我想从长按菜单进入多选，勾一堆歌一次删掉，而不是一首一首来。
13. 作为使用者，我想多选模式下看得见勾了几首。
14. 作为使用者，我想退出多选模式是件容易的事。

### 回收站

15. 作为使用者，我想在 App 里看到回收站里有什么、占了多大空间。
16. 作为使用者，我想把误删的歌一键恢复回原处。
17. 作为使用者，我想清空回收站时有个明确的二次确认，因为那是唯一真删数据的操作。
18. 作为使用者，我想知道回收站不会自己清理——我的东西不会莫名其妙消失。

### 安全

19. 作为使用者，我想这些危险接口有把锁，局域网里别人不能删我的曲库。
20. 作为使用者，我想密钥对不上的时候，搜歌和下载**照常能用**——锁只锁危险的那几个接口。
21. 作为使用者，我想电脑上的服务没开时，得到一个说得清楚的提示，而不是转圈或者崩掉。

## 明确不做（这一版）

- **不同步改磁盘文件名**。改歌手/专辑标签之后，文件夹名和标签会对不上——**这不影响使用**（Jellyfin 认标签不认文件夹），也不是 bug。
- **不催 Jellyfin 刷新**。靠它自己的实时监控发现文件变化。**已知风险**：如果实时监控只盯"新增"不盯"修改"，改标签后重启 App 可能显示回旧名，直到 Jellyfin 全量扫描。待实测，真有问题再补。
- **不自动清理回收站**（ADR-0002）。
- **不做播放列表管理、不换封面、不做归档移动**（用户明确只要了批量删除）。
- **不加独立的"文件管理"页面**。入口只有长按菜单 + 设置页的回收站。
