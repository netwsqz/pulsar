# 02 — 删除流派页

**What to build:** 顶层导航不再有「流派」。使用者只看得到发现、歌曲、专辑、艺术家、播放列表五个页签；点艺术家仍能正常进入该艺术家的专辑列表。流派相关的空态、文案、分组分支一并消失，`Album.genres` 数据字段保留。

**Blocked by:** 无 — 可立即开始。

**Status:** ready-for-agent

**规格参考：** `spec.md` §12

- [ ] 顶层导航恰为发现、歌曲、专辑、艺术家、播放列表；`navIndex` 按列表位置推导，测试按类型断言而不是硬编码索引。
- [ ] 界面上不再出现「流派」入口、空态或文案；点艺术家进入的组详情正常。
- [ ] 分组只按艺术家；大小写不敏感、空白/UNKNOWN_ARTIST 不建组、稳定排序的既有边界用例通过。
- [ ] `Album.genres`、DTO 与 `Fields=Genres` 保持不变。
- [ ] 新增 ADR 0009 记录删除理由，并在 ADR-0008 的范围列表注明流派页已删除。
- [ ] 构建与单测通过。
