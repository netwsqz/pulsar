# 05 — 迷你播放条减法与队列面板

**What to build:** 迷你播放条做减法：360dp 屏上歌名有足够宽度，折叠态只保留封面、歌名/歌手、播放/暂停、展开；没有在播内容时播放键是灰的、点了没反应；展开后的队列标题和移除按钮都够大、层级清楚；空态封面不再是直角灰块。

**Blocked by:** 01（设计 token 收口与设置页底部留白）、03（GlassPanel 玻璃面前景色统一）。

**Status:** ready-for-agent

**规格参考：** `spec.md` §4

- [ ] 360dp 宽屏文字列 ≥160dp；歌名显示明显变长。
- [ ] 折叠条只保留封面、歌名/歌手、播放/暂停、展开；上一首/下一首不再出现，全屏页与横滑切歌手势仍可用。
- [ ] 无媒体时播放/暂停禁用且无反应。
- [ ] 队列分区标题与歌名在字号/字重上可区分；标题行和移除按钮热区 ≥48dp，移除图标保持 16dp。
- [ ] 没有在播内容时，迷你条封面是与其它封面一致的圆角占位。
