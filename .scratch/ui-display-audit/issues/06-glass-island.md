# 06 — 玻璃岛三段式与「更多」菜单

**What to build:** 顶部玻璃岛变成三段：左边搜索、中间可横滑的页签、右边一个「更多」。设置和退出登录收进「更多」，退出前先确认；页签不再被设置/退出图标挤压。已下载列表和 QQ 音乐导入仍从设置页进入，不另开全局入口；不新增底部导航。

**Blocked by:** 01（设计 token 收口与设置页底部留白）、02（删除流派页）、03（GlassPanel 玻璃面前景色统一）。

**Status:** ready-for-human（代码完成）

**规格参考：** `spec.md` §3

- [x] 玻璃岛从左到右为搜索、可横滑页签、更多；不再有独立的设置/退出图标。
- [x] 页签顺序完全由 `TopLevelSections` 决定；切到靠后页签时可横滑看到。
- [x] 「更多」只包含设置和退出登录；退出登录先弹确认，取消后仍保持登录。
- [x] 设置页里的「下载」和「QQ 音乐导入」入口不变。
- [x] 没有新增底部导航，内容区高度不被压缩。
- [ ] 构建通过；真机验证。

## Comments

### 实现记录（2026-11-01，agent）

**改了什么**

- **玻璃岛三段式**：`MainActivity.kt` 的 `GlassChipBar` 按 spec §3 重排为
  搜索（48dp）→ 页签区（`weight(1f)` + 横滑 + 两侧渐变遮罩）→「更多」（48dp）。
  `TopLevelSections.forEachIndexed` 与 `bringIntoView` 原样保留，页签顺序仍只由
  `LibrarySection.kt` 的 `TopLevelSections` 决定，没有写死索引。
- **「更多」菜单**：用 Material3 `DropdownMenu`，只收「设置」「退出登录」两项；点击后先关菜单再动作，
  避免菜单盖在新页面上。原来的设置 / 退出两个 `IconButton` 删除，`ExitToApp` / `Settings`
  两个已无引用的 import 一并清掉。
- **退出二次确认**：`AlertDialog`（标题「退出登录？」，取消 / 退出登录）。确认前不调用
  `viewModel.signOut()`，取消即保持登录。文案说明「已下载的歌曲会保留在手机上」——
  与 `signOut()` 只清会话与曲库快照、不清下载（ADR-0007）的实际行为一致。
- **设置入口不变**：已下载列表（设置 → 下载）与 QQ 音乐导入（设置二级页）未动，
  没有新增全局入口，没有新增底部导航；玻璃岛高度仍是 `Dimens.GlassIslandHeight`（56dp），
  内容区占位 `GlassIslandTopSpacing` 不变。
- **文档**：`CLAUDE.md` 里过时的「`LibrarySection.QQDownload`，顶部玻璃岛有「QQ 下载」chip」
  改为「`LibrarySection.DownloadService`，从设置 → QQ 音乐导入进入（ADR-0006）」，
  与本单「QQ 导入仍从设置页进入」的口径一致。

**代码审查（Standards / Spec 并行两轴）**

- 两轴均无阻塞项。Spec 轴逐条核对：三段布局、`TopLevelSections` 单一来源、横滑、
  菜单两项、退出确认、设置入口不变、无底部导航，全部落实。
- Standards 轴的 judgement call 未改：①`GlassChipBar` 现在同时管页签 / 搜索 / 更多 / 退出确认，
  名字偏窄——它是玻璃岛唯一入口，拆出去反而多一层跳转，保留原名；②两个菜单项的
  「先关菜单再动作」两行内联，未抽 `closeAnd` 式小工具；③两个布尔状态没有合并成密封类，
  当前赋值顺序保证互斥；④「更多」菜单用 Material3 菜单、与长按菜单的自绘玻璃样式不同，
  菜单样式统一是工单 15 的范围。
- **残余风险**：前置工单 01 / 03 仍待真机验收；若它们调整 `GlassPanel` / `Dimens`，
  本单需一起回归。菜单 Popup 在深色主题下的容器色沿用 M3 默认，真机确认可读性即可。

**真机待验清单（360dp × 深/浅色各一遍）**

1. 玻璃岛从左到右：搜索、页签、更多；设置 / 退出图标已消失，页签可见宽度明显变宽。
2. 左右横滑页签，滑到「播放列表」；切到靠后的页签时自动滚入可见区。
3. 点「更多」→ 只有「设置」「退出登录」两项；点「设置」进入设置页，返回仍回来源页。
4. 点「更多 → 退出登录」→ 弹确认；点「取消」后仍在原页面且保持登录；再确认一次才回登录页。
5. 设置页里「下载」与「QQ 音乐导入」入口照旧可用。
6. 内容区高度与改动前一致，没有新增底部导航、没有横向溢出。
