# 07 — 歌曲与搜索列表行（含共用空态/文案）

**What to build:** 歌曲页和搜索页的列表行用同一套语法：前槽、间距、文字列、尾槽一致；多选时分隔线从文字左缘开始；骨架和真实行同高，加载完不跳；空态居中；行尾按钮和勾选框都有足够热区。歌曲页标题直接叫「歌曲」，离线提示的字号不低于行内副标题。

**Blocked by:** 01（设计 token 收口与设置页底部留白）。

**Status:** ready-for-agent

**规格参考：** `spec.md` §5、§11

- [ ] 歌曲页、搜索页的曲目行使用同一套槽位，行高和按钮位置一致。
- [ ] 标题一行 bodyLarge，副标题一行 bodySmall 次要色；当前曲目标题用 primary。
- [ ] 多选时分隔线从文字左缘开始，不穿过勾选框；无多选时从封面右侧开始。
- [ ] 行骨架与真实行同高、同槽位；加载完成内容不向上跳。
- [ ] 空态图标和文案居中且撑满宽度；错误态同样。
- [ ] 行尾「更多」/勾选框热区 ≥48dp。
- [ ] 歌曲页标题显示「歌曲」，不再显示「你的音乐」；离线提示字号不低于行内歌手副标题。
- [ ] 构建通过；真机验证歌曲/搜索/多选/骨架/空态。
