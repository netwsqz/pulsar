### 实现记录（2026-11-02，agent）

**改了什么**

- **页面骨架**：`PlaylistDetailContent` 从「固定头部 Column + 内层 LazyColumn」改成整页一个
  `LazyColumn`，真实头部是第一项。加载时只在头部下面接曲目骨架行，不再复用带假头部的
  `AlbumDetailSkeleton`——那份已随本单删除（它唯一的使用点就是播放列表详情）。
- **头部改成与专辑详情同一语言**（spec §6 / 报告 §4.3）：封面 `fillMaxWidth(0.62f)` + 1:1 +
  `Dimens.CornerLarge`；标题 `headlineSmall` 粗体居中 `maxLines=2 + Ellipsis`；副标题
  「播放列表」`bodyLarge` 次要色；摘要 `bodySmall` 次要色；间距全走 Dimens。头部随页面滚动，
  长标题不再挤压曲目列表（原设计里并排的文字列因此不再存在，`weight(1f)` 那条以「头部不再
  与列表争高度」的方式满足）。
- **动作行**：新增「播放全部」「随机播放」，与专辑详情的回调/禁用条件一致，作用于当前
  可见曲目（离线已过滤）。下载按钮位置与专辑详情对齐，离线仍隐藏。
- **摘要计数**（新纯函数 `PlaylistSummary.kt` + `PlaylistSummaryTest.kt`）：曲目已加载用
  列表长度、未加载才退回 `trackCount`；离线视图写「已下载 N 首 · 共 M 首」，M 取服务端总数
  且不小于实际行数。
- **离线**：头部补 `OfflineNoticeText`（离线过滤生效时）；未下载的列表改说明型空态
  「离线 · 这个播放列表没有下载，需要联网才能查看」，不再给必然失败的重试按钮；离线读取
  本地清单期间先给骨架，不闪「没有下载」。
- **其他**：曲目行间距保持原来的 `Dimens.SpaceTiny`（与骨架 `rowSpacing` 一致，加载完不跳）。
