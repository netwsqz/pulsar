# ADR-0008：离线只显示已下载，取消「全量 + 置灰」

**状态：** 已接受（2026-10-28）

**部分取代：** [ADR-0007](0007-downloads-replace-auto-cache.md) 里「离线时其余标灰不可播」的界面口径（下载不可自动删、播放链路只读等决定仍然成立）

## 背景

ADR-0007 定下的离线口径是「全量可见 + 没下载的置灰」：曲库快照撑起各屏，没下载的歌压到 0.38 透明度，点了弹「这首歌没有下载，联网后才能播放」。

真机上用下来，这个设计把「我现在有什么」和「曲库里有什么」混在同一屏里：

- **置灰的歌占了列表的绝大多数。** 下载通常只有几十首，曲库几百上千首——离线打开 App，满屏都是点不动的灰行，真正能听的埋在中间。
- **灰行没有任何操作价值。** 点它只会弹提示，既不能下载（离线）、也不能加入队列、也不能进详情听到什么。留着它只是「让用户知道自己缺什么」。
- **发现页尤其糟。** 每日推荐从全量曲库里挑 4 首，离线时大概率全是灰的——第一屏就点不动。
- **搜索页同理。** 搜出来的大半是灰的，「搜到了但放不了」比「没搜到」更让人困惑。

## 决定

**离线时曲库各屏只显示已下载的东西，置灰整套 UI 删除。**

**1. 范围：所有曲库内容页。**

发现、歌曲、专辑、艺术家、组详情、专辑详情、播放列表详情、离线搜索（流派页已按 [ADR-0009](0009-remove-genres-page.md) 删除）。QQ 音乐导入、设置、设置里的「已下载」管理页不在此列（前两者不是曲库浏览，后者本来就是本地字节管理）。

**2. 粒度：专辑有一首已下载就显示。**

选曲下载是支持的，只下 3 首的专辑不该整张消失。艺术家组从这批专辑现算。代价与既有离线专辑详情一致：`Track` 只有专辑名没有专辑 id，同名不同歌手的专辑会并在一起。

**3. 详情页只列已下载曲目，并隐藏下载按钮。**

离线时详情页的列表已经全是下载过的，再给「下载」按钮既点不了也没意义。

**4. 过滤在界面层派生，原始状态不动。**

`JellyfinUiState` 里的 `tracks / albums / albumTracks / ...` 保持全量——断网恢复在线时 App 只靠一次探活翻回在线，「歌曲」页不会自动重拉，改原始数据会让列表永久缩水。派生逻辑抽成纯函数 `offlineVisibleLibrary()`，在 `MusicLibraryScreen` 算一次往下传。

**5. 发现页的本地内容也按同一口径。**

每日推荐只从已下载里挑；随机专辑只显示还有已下载曲目的专辑。三节服务器历史（最近播放 / 最常播放 / 最近添加）本来离线就取不到，照旧隐藏。离线时下拉刷新只重排本地内容，不发必然失败的请求。

**6. 一首都没下载时给专用空态。**

「离线 · 手机里还没有下载的歌曲」，而不是「暂无音乐」——用户要能分清「曲库空了」和「离线只能看下载」。

**7. 播放队列不动。**

断网前已经排进队列的未下载歌继续留在队列里，播到那首交给现有的播放失败逻辑。`isPlayable` / `unplayableReason` 保留，只服务这个场景（以及新点播/新入队的守门）。

**8. 判不出「哪些已下载」时按没有处理。**

下载层异常已经被吞掉，退化成空集合、显示空态。不为此再加一层「未知」状态。

**9. 离线时隐藏长按菜单里的「改名 / 删除」。**

这两项走 PC 伴生服务，断网必然失败。藏起来比让用户点了等报错好。

## 理由

**为什么不是「保留灰行但改成可点」**：离线时点了也放不出来。任何「看起来能点、点了不行」的入口都是纯负担。

**为什么不干脆把离线搜索也关掉**：搜索是找歌的主要入口，离线时只搜已下载仍然有用——「我下过那首吗」是个真问题。界面上标「离线 · 只搜已下载」，范围说清楚就行。

**为什么在界面层派生而不是改 state**：探活回在线时「歌曲」页不会重拉（它没有 LaunchedEffect key 触发），改 state 会让列表一直缩水到用户手动刷新。派生方案天然满足「回在线自动恢复全量」。

**为什么队列不清**：这次改的是「显示」。清队列会连带切掉正在播的歌，收益远小于代价。

## 被否掉的方案

- **保留灰行、只是不再弹提示**：满屏点不动的行依旧存在，这次要消灭的正是它。
- **整张下完才显示专辑**：选曲下载的专辑会完全消失，那几首已下载的歌无处可去。
- **断网时清空队列里的未下载歌**：正在听的歌会被切掉。
- **把 `cachedTrackIds` 改名成「离线可见集合」**：牵动 4 处引用和一批测试，收益只是措辞，字段名保留、注释改口径。

## 后果

- **断网那一刻列表会立刻变短。** 靠各内容页标题下的一行小字「离线 · 只显示已下载」解释，不做过渡动画、不弹窗。
- **`TrackRow` 的 `dimmed` 分支、`OfflineState`（带 `onUnplayable`）整段删除。** 换成只表达「是否离线」的 `LocalOfflineActive`，供长按菜单判断要不要藏文件操作。
- **`JellyfinUiState.cachedTrackIds` 的语义变成「离线可见集合」**，字段名不变。
- **离线时发现页可能整页只有几条。** 只下了 3 首就是 3 首，这是诚实的——离线能力本来就等于「下过什么」。
- **文档口径要跟着改**：`CONTEXT.md`（曲库快照、已下载判据）、`CLAUDE.md` 离线那条、`.scratch/download-instead-of-cache/spec.md` 用户故事 12、issue 08。`.scratch/library-cache/` 那批是历史记录，保留原词。
