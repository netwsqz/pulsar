# ADR-0012：曲库由 PC 伴生服务提供，分阶段替换 Jellyfin

**状态：** 已接受（2026-11-22）；尚未正式切换

Pulsar 继续播放电脑上原有的曲库，不搬音频文件。现有 PC 伴生服务接手读取曲库和提供原文件，也负责存新播放列表；不再安装另一套通用音乐服务器。场景只覆盖个人在家中局域网听歌：手机用 PC 地址和访问密钥配对，不做公网直连或多账号系统。

先用独立入口跑通配对和播放，保留原入口。只有存量下载能在断网时继续播放、新播放列表可编辑、其余切换条件通过后，才让伴生服务成为默认曲库来源。旧播放列表和旧听歌记录不导入，原数据不删；迁移下载时不要求启动或调用 Jellyfin。

[ADR-0007](0007-downloads-replace-auto-cache.md) 关于手动下载、不自动清理、仅完整副本算已下载的决定继续有效。本次要接回的是用户主动下载的副本，不是 ADR-0007 当时放弃迁移的自动缓存。[ADR-0011](0011-session-credentials-owned-by-session-manager.md) 的凭据单一持有原则继续有效；试用入口不覆盖旧会话或串用两种服务的凭据。

实施范围和验收条件见 [脱离 Jellyfin：规格与工单草稿](../companion-library-cutover.md)。
