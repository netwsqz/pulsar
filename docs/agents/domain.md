# 领域文档

本仓库是**单上下文**（单 Gradle 模块 `app`，无 `CONTEXT-MAP.md`）。

## 探查前先读

- 仓库根 `CONTEXT.md`：术语表，写工单 / 测试名 / 代码注释时用那里的词，不漂移到它明确回避的同义词。
- `docs/adr/`：只读与改动区域相关的 ADR。与已有 ADR 冲突要明说，不要悄悄覆盖。
- 需要用但术语表里没有的概念：先怀疑自己造词；确实是缺口就记下来交给 `/domain-modeling`。

## 本仓库补充

- **语言**：代码注释、`CLAUDE.md`、`docs/` 下的文档一律中文；与用户沟通也默认中文。
- **先找现成结论**：`docs/` 下的专题文档（USB 调研、音量键拦截、各重构规格）和 `docs/archive/`（过时归档，只作历史）都可能已有答案，动手前扫一眼，别重复调研。
- **`CLAUDE.md` 是事实上的架构地图**（数据层 / 播放 / USB / UI 约定与红线），比 `CONTEXT.md` 更全，优先读它。
