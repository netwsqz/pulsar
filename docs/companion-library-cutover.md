# 脱离 Jellyfin：规格与工单草稿

## 目标和边界

- 手机继续在家中局域网播放电脑曲库 `E:\file\Te_Music`，音频不搬家、不转码；运行现有 PC 伴生服务即可，无需运行 Jellyfin。服务只给单人使用，不需要账号注册或公网访问。
- 手机首次填 PC 地址和访问密钥配对，重开 App 可自动恢复。访问密钥独立于文件操作密钥和 QQ 凭证，只发给所配对的服务，不进 URL、日志或媒体项；输入时遮盖，不在页面回显已保存的密钥。局域网 HTTP 不加密，首版只用于可信家庭网络，不开放公网端口。
- **只迁手机已有下载。** 原安装直接升级，不卸载、不清数据、不要求重下。旧播放列表不迁，但经旧播放列表下载的完整歌曲仍要保留。新播放列表存电脑、从空白开始；旧听歌记录不迁，新记录从零积累。
- 正式切换时，有内嵌封面就显示，没有就用默认图；补歌词与补缺失封面不作为切换条件。保留既有顶层导航、播放会话和手动下载原则。
- 迁移不调用 Jellyfin API、不要求启用旧服务，不改旧数据文件。预览、试用和正式切换分开；正式切换与真机安装另行确认。

## PC-01：不用 Jellyfin 也能播放一首歌

**依赖：** 无。首项只实现这个闭环，不接入下载、播放列表、听歌记录或歌词，不改变默认曲库来源。

- **电脑端**：在现有伴生服务加独立只读接口，复用 `server/library_index.py` 的扫库路径和内嵌标签规则，不依赖 QQ 凭证或 Jellyfin。向手机提供歌曲清单和按曲目 ID 取原音频，不接收客户端指定的文件路径。曲目 ID 在重启、重扫和改内嵌标签后保持一致；仅能读曲库内的音频。支持 HTTP Range，以便播放器定位。
- **手机端**：保留旧入口并提供独立「电脑曲库」入口，尚未登录 Jellyfin 和已有 Jellyfin 会话都能打开。配对成功后保存新连接，错误密钥或暂未连上时给可重试提示，不覆盖旧会话、曲库快照或下载名单。列表标清空曲库与连接失败；点歌走现有 `PlaybackSession` / `PlaybackService`，不将凭据放进播放地址、不将新曲目的播放报告发给 Jellyfin、不因播放写入下载。
- **数据流**：配对读取有鉴权的歌曲清单 → 点击歌曲时向播放会话提交曲目 → 播放服务只向已配对的 PC 流地址附加访问鉴权 → 直接播放原文件。
- **建议自动测试入口**：① PC 服务的 HTTP 接口（无有效密钥不能列歌或读音频；有密钥能列临时曲库、取原字节与跳播所需区间）；② Android 的配对及播放请求边界（配对成功才保存、重开无需重填、媒体地址无密钥、不会将鉴权发给错误的服务）。用临时曲库和测试密钥，不读写真实用户数据。
- **验收**：全量 Android 单测和 `assembleDebug` 通过；电脑伴生服务单测通过。真机由用户确认：Jellyfin 未运行，不登录 Jellyfin，在同一局域网配对，列表出现、点歌有声，拖进度继续播放，重开 App 不重填。两端分别通过测试不等于真机已验收。

### 真机验收步骤（PC-01）

1. 电脑只需手动运行更新后的 PC 伴生服务（见 [`server/README.md`](../server/README.md)）；验收时 Jellyfin 不运行。手机和电脑在同一个可信家庭局域网内，电脑有线连接到同一路由器也可以。
2. 原 APK 同包覆盖安装，不卸载、不清数据。未登录时从登录页点「连接电脑曲库（试用）」；已有 Jellyfin 界面可从「更多 → 设置 → 电脑曲库（试用）」进入，不必先退出旧账号。
3. 填电脑局域网 IP（默认端口 `8900`）。打开电脑端 `server/.library_access_key`，把文件中的值填进访问密钥框，不贴到聊天、工单或日志。首次扫描还没完成时等一下再试。
4. 配对后选一首电脑曲库中的歌确认听得见，拖进度后核对声音从新位置继续。退出再打开 App，重新进入试用入口，确认不用重输密钥就能列歌。此版本不把试用曲库设成默认来源。

## PC-02：接回已有下载

**依赖：** PC-01。

- 先做只读核对：原账号的下载名单、完整副本和旧播放用的缓存键必须对得上。旧数据库可提供「旧曲目 ID → 电脑文件路径」，结合手机的曲库快照和已下载列表清单；不凭歌名猜，不拿路径相同当作原文件一定未替换。
- 能确认的完整副本复用原音频字节，按新曲库或明确的「已有下载」分组可打开，包括旧列表下载的歌曲。不清空或搬动原副本，不让未下完的歌算已下载。无法核对的项单独报告，保留原数据并提供可验证的保留方案；不能把恢复一部分当作完成。
- 核对预览可重复运行；真正应用前确认影响范围。验证同包升级、不重下，切换为飞行模式后冷启动，能从已下载列表打开并播放原有完整副本。

## PC-03：新播放列表

**依赖：** PC-01。

- 伴生服务持久化新播放列表；新库初次打开时列表为空，不读取或修改旧列表。配对后可新建列表、加删歌曲、调整顺序。改列表不改音频文件，不触碰旧下载。
- 验收：从「电脑曲库（试用）→ 播放列表」新建列表，打开「编辑曲目」，添加三首歌。用上移 / 下移改顺序，再移除其中一首，点「保存顺序」。移除只影响播放列表，不删除音频或手机上的下载。
- 完全关闭并重开 App，再重启 PC 伴生服务；每次都回到原播放列表页，检查名称、剩余两首歌和顺序。点「播放全部」，听到声音并核对队列顺序；再点列表里不是第一首的歌曲，确认从该曲目开始播放且队列仍保持原顺序。验收时 Jellyfin 保持关闭，覆盖安装另行确认；自动测试不替代真机验收。
- 自动化门禁（2026-11-27，#47）：Android 全量 1041 个单测、PC 全量 162 个单测、Debug APK 构建均通过。覆盖鉴权隔离、服务重启保序、保存失败不覆盖、断连转离线，以及从非首曲起播仍保持队列顺序。未覆盖安装，真机验收待用户完成。

## PC-04：新曲库接入日常使用

**依赖：** PC-01。

- 让原浏览入口、专辑/艺术家、合并搜索、QQ 音乐导入和文件操作在选用新曲库时不再借 Jellyfin 会话工作；不新增顶层页签。新曲库仍能手动下载原文件，电脑关机时曲库离线只显示已下载。
- 接入内嵌封面与默认图。听歌历史从零记起，恢复发现页「最近播放／最常播放／最近添加」；不上报给 Jellyfin，不迁历史。
- 验收：从搜索和专辑能找到并播放同一首歌；PC 导入后能刷新看到曲目；已有播放、下载与文件操作约定不回退。无封面的歌能正常显示和播放。

## PC-05：正式切换

**依赖：** PC-01、PC-02、PC-03、PC-04。具体用户体验和验收用例见[无感替换规格](companion-library-seamless-cutover-spec.md)。

- 逐项验证新配对、播放、播放列表、新下载与旧下载。配对场景验证 Jellyfin 全程关闭；旧下载另外验证飞行模式下可播。用户确认后才切换默认入口；原安装数据和旧 Jellyfin 数据留存，保留回退路径直到接受切换结果。
- 不做公网开放、手机本地曲库、多用户、旧列表/历史导入、在线补封面与歌词，不在本轮卸载旧服务或删除文件。
