## #42 真机验收

1. 确认可覆盖安装后，用原安装更新。**不卸载、不清数据。** 电脑和手机连同一个可信局域网；验收期间不要运行 Jellyfin。仅手动启动 PC 伴生服务（见 [PC 服务说明](../server/README.md)）。
2. 登录页点「连接电脑曲库（试用）」；已有会话也可从「更多 → 设置 → 电脑曲库（试用）」进入，不需要退出旧账号。输入电脑局域网地址和 `server/.library_access_key` 中的访问密钥，不把密钥贴到聊天或工单。有扫描提示就等扫描完再试。
3. 确认列表出现，点一首歌**听到声音**；把进度拖到曲目中段，确认能**从新位置继续出声**。
4. 完全关闭再打开 App，重新进入试用，确认不重填地址和密钥就能列歌。

用户已回复 #42 真机验证完成；#44 接续此结果，不把它当作新包的验收。

## #44 真机待确认：原歌曲页和合并搜索

1. 单独确认覆盖安装后，保持 Jellyfin 关闭，用原入口打开「电脑曲库（试用）」。应沿用配对，直接进入原「歌曲」页，不用填旧账号，也不用再填密钥。
2. 在「歌曲」点一首歌，打开原来的迷你播放条、全屏播放页及队列；拖到中段确认继续出声。再用左上的搜索搜同一首歌，从结果中点播，核对是同一首。曲库结果在 QQ 音乐前；若 QQ 提示凭证过期，曲库结果仍可播放。
3. 可暂停伴生服务后点「刷新」验证断连提示；手动重启伴生服务后点「重新加载」，应不重配就能恢复。扫描中、密钥失效和真实空库用自动测试覆盖，不必动真实密钥或搬走文件。
4. 从「更多 → 退出电脑曲库试用」回到旧入口。发现、专辑、艺术家、播放列表仍保留原页签，试用里不调用 Jellyfin 加载这些页；不改默认来源，不迁移手机上的下载。

本次构建没有安装到手机，以上 #44 真机步骤待验收。

## 额外核对：预览旧下载（#43）

从「设置 → 下载 → 预览旧下载」打开；已保存旧账号但离线回到登录页时，也能从登录页打开。预览只读本机数据，按曲目列出「已核对完整」「未下完」「待核对」和数量，相同曲目跨多个下载批次只算一次。未保存旧账号时会说明不能确认归属。访问不了 Jellyfin 不妨碍预览；预览本身也不会迁移或让旧副本接到新曲目上。
