# 已有下载：飞行模式验收清单（#45）

本轮只把能确认归属、且字节完整的旧副本接到原「已下载」页的「已有下载」分组。不关联电脑曲库里的新曲目（#46），不迁旧播放列表、不改默认曲库来源。旧下载名单、曲库快照和音频都不搬、不改写、不自动删。

- Android：1030 个 JVM 单测通过，覆盖确认、失败重试、账号隔离、原读取定位和在播副本保护；Debug APK 构建通过，产物 `app/build/outputs/apk/debug/app-debug.apk`。

## 真机验收（待用户确认）

1. 先确定手机上保留着旧账号，并各有至少一首从旧专辑、旧播放列表手动下载且已下完的歌；最好再选一首未下完的旧下载作对照。保持 Jellyfin 不运行。确认后才覆盖安装同包 Debug APK，**不卸载、不清数据**。
2. 打开「已下载」：原曲库走「更多 → 设置 → 下载 → 已下载」，电脑曲库试用走「更多 → 已下载」，回到登录页也可以直接点「已下载」。打开「预览旧下载」，核对「已核对完整／未下完／待核对」和数量。先点取消，确认「已有下载」没有变化。
3. 获准应用这批真实副本后，再打开预览，点「确认加入已有下载」。核对两种下载中完整的曲目都列出、重复曲目只列一次；未下完或待核对项不能播。这个操作只登记可复用的副本，不代表所有旧下载都已恢复，也不会创建新播放列表。
4. 完全关闭 App，打开飞行模式并确认 Wi-Fi 也关闭，再冷启动；不要先联网打开曲库。进入「已下载 → 已有下载」，分别点旧专辑下载和旧播放列表下载各一首，**亲自听见出声**；再拖进度到曲目中段，听声音是否从新位置继续。可在这里打开原迷你播放条、全屏播放器和队列。
5. 若看见「原副本暂不可播」或「待核对」，记录对应曲目和提示，不重下、不删文件，不将部分可用算作全部恢复。如果要验证再次同包覆盖后的首次冷启动，在本轮确认加入后、下一次打开 App 前保持飞行模式，另行确认覆盖安装操作。

设备测试只使用临时缓存中的合成字节，不读取真实下载。它验证重开缓存后能从原键读取指定区间、缺口不走网络，不能替代上述出声验收。

## #46：从电脑曲库复用已核对的旧副本（待真机验收）

自动化验证：Android 1033 个 JVM 单测、PC 157 个单测、Debug APK 构建均通过；设备测试已编译，未运行。未覆盖安装或应用真实关联。

1. 另行确认后更新手机与 PC 伴生服务；不启动 Jellyfin，不卸载 App、不清数据。先完成上面的「确认加入已有下载」。
2. 保持电脑在线，打开「电脑曲库（试用）→ 更多 → 已下载 → 核对与电脑曲库的关联」。核对可关联数与未匹配数，先关闭验证未应用，再另行确认是否应用这批关联。不会重下或移动音频，不导入旧播放列表，也不切换默认曲库。
3. 冷启动前打开飞行模式并关掉 Wi-Fi，打开试用。在原「歌曲」页和合并搜索找到同一首已关联曲目，分别点播并拖到中段，亲自听见出声。未匹配的完整旧副本仍从「已有下载」播放，不以同名或同路径自动替代。
4. 缺旧路径、电脑文件移走或任何字节不同（含标签变化）都可能匹配不上；这些情况不清副本。在线刷新能发现已移走或文件版本变化的曲目；离线只能使用上次核对过的状态，不能发现电脑关机期间的变化。不必改动真实曲库来制造对照，替换文件和同名异曲由自动测试覆盖。

## #49：手动下载电脑曲库的原文件（待真机验收）

自动化验证：Android 1038 个 JVM 单测、PC 159 个单测、Debug APK 构建均通过；设备测试已编译，未运行。

1. 另行确认后更新手机和 PC 伴生服务；保持 Jellyfin 不运行，不卸载 App、不清数据。在「电脑曲库（试用）→ 歌曲」或合并搜索找到一张未下载的测试专辑，长按歌曲选「打开专辑」。这一入口只用于试用下载，不等于完整的专辑、艺术家浏览已接入。
2. 先只在线点播一首，确认「更多 → 已下载 → 电脑曲库下载」没有新增。再回专辑详情点「下载」，观察进度。若在一首下完后取消，已下完的可见，未下完的不显示；重新点下载继续补齐。蜂窝流量下应先询问。
3. 下载完成后完全关闭 App，打开飞行模式并关闭 Wi-Fi，再冷启动进入「电脑曲库（试用）」。确认「歌曲」和合并搜索只显示已下载的歌，并标明离线。从「更多 → 已下载 → 电脑曲库下载」展开专辑点播，再从歌曲或搜索点播，分别听见出声、拖到中段继续出声。
4. 只用这次专门下载的测试副本验证删除：正在播放的一首不能删，整张删除也保留它；停止播放后再删。确认「已有下载」和电脑原文件不受影响。无需修改真实曲库来制造文件版本变化，自动测试覆盖了替换文件后拒绝旧版本续传。
