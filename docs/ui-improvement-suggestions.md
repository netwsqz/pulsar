# Pulsar UI 优化建议清单

> 生成于 2026-08-20。基于对现有代码的全量审计（MainActivity.kt 全部屏幕 + 主题系统），
> 对照 Apple Music（iOS 26 液态玻璃设计语言）与 Spotify 手机端 2025-2026 最新设计的调研。
> 每条建议带现有代码锚点（函数名 + 大致行号），按「性价比」分三档。

---

## 总评

**现有 UI 底子相当好，不需要推翻重来。**

已有的强项（审计确认）：

- 真·液态玻璃而非贴图模拟：顶岛和播放条用 kyant0 backdrop 的 vibrancy + blur(16dp) + lens 三效果叠加，内容能真的滚到玻璃下透出
- 封面取色背景渐变系统完整（Coil 96px 小图 + androidx.palette + HSL 柔化 + 800ms 平滑过渡 + 无封面回退主题色）
- 分区切换有方向感知的转场（进详情右推、列表间轻滑 + fade，320ms 统一节奏）
- 长按上下文菜单动画精细（触觉 + 锚定触点 Popup + 弹性 spring + 菜单项错峰上浮）
- 网格页骨架屏结构复刻度高，状态三分（loading/error/empty）在 9 个数据分区中 8 个齐全
- 中文无障碍覆盖完整，字体有真实配对策略（Righteous + Poppins 五字重）

和两大标杆的核心差距就三件事：

1. **没有全屏播放页** —— 点播放条只展开一个小面板，没有大封面沉浸页，音乐播放器最核心的仪式感场景缺失
2. **正在播放的歌在列表里认不出来** —— 翻遍全部音乐/专辑/搜索都看不出哪首正在放（只有队列面板有高亮）
3. **细节反馈没跟上** —— 触觉只覆盖 2 处、列表行无按压效果、迷你条上看不到播放进度

## A 档：小改动大效果（每项半小时到两小时）

### A1. 正在播放的曲目高亮 + 跳动音符条 ⭐ 性价比第一

- **做出来什么样**：正在播放的歌，行首显示 3 根随节奏跳动的「均衡器条」（暂停时静止变灰），歌名变成主题色。一眼认出哪首在放。
- **参考**：Apple Music 的招牌细节——正在播放的曲目编号位置换成 3-4 根跳动的红色均衡器条；Spotify 同款（换绿色）。这是「音乐 App 正在呼吸」的心跳。
- **怎么改**：`TrackRow()`（MainActivity.kt:857）加 `isCurrent`/`isPlaying` 参数，用 `rememberInfiniteTransition` 画跳动条；四个调用处（全部音乐/专辑详情/播放列表详情/搜索）把当前曲目 id 传进去比较。

### A2. 迷你播放条底部贴一条细进度线

- **做出来什么样**：玻璃条最底边一条 2-3dp 的细线，从左往右随播放增长，不用展开就知道播到哪了。
- **参考**：Spotify 迷你条的标志设计——细进度线贴在条底边缘横贯全宽、无手柄。扫一眼就知道歌进行到哪。
- **怎么改**：`MiniPlayerBar()`（MainActivity.kt:1865）玻璃容器底部加一个 Canvas 画线，宽度 = 进度 × 条宽，用已有的 500ms 轮询数据。

### A3. 关键操作补触觉反馈

- **做出来什么样**：按播放/暂停、切歌、加队列成功时手机轻轻震一下，操作有「被接住」的确认感。
- **参考**：Apple 的原则——触觉只用在「状态改变成功」的时刻，用得越少越珍贵；Spotify 在切歌、收藏、进度条松手时给短促 tick。
- **怎么改**：现在全 App 只有 2 处触觉（TrackRow 长按 877、队列拖拽 1885）。在播放/暂停、上一首/下一首、加队列这几个按钮的 onClick 里各加一行 `hapticFeedback.performHapticFeedback(...)`。

### A4. 长歌名跑马灯滚动

- **做出来什么样**：迷你条上超长歌名静止 2 秒后自动向左滚动，把全名看完；不溢出就永远不动。
- **参考**：Apple Music 标配行为（静止约 2s → 滚动 → 停顿 2s → 循环）；列表行内一律截断不滚动。
- **怎么改**：Compose 自带 `Modifier.basicMarquee()`，迷你条歌名、详情页标题加上就行，一处一行。

### A5. 列表行加按压反馈

- **做出来什么样**：点曲目行时有水波纹/按压缩放，点击有视觉确认（现在 pointerInput + detectTapGestures 绕过了 clickable，点了没任何反馈直接就播了）。
- **怎么改**：`TrackRow()`（873-883）换成 Material3 的 `combinedClickable`（自带点击水波纹 + 长按），长按菜单逻辑照搬。

### A6. 三个 bug 级小修（打包一次做）

| 问题 | 锚点 | 修法 |
|------|------|------|
| QQ 下载页音质 chip 行固定 4 个 chip 不带滚动，窄屏溢出截断 | QQDownloadScreen.kt:124 | 加 `horizontalScroll` |
| 睡眠定时滑块 0-60 分钟能拖出 37 分钟这种非整值 | MainActivity.kt:1809 | 加步进或 15/30/60 预设档 |
| Snackbar 写死底部 80dp，播放条展开后提示被玻璃条盖住 | MainActivity.kt:623 | SnackbarHost 位置跟随播放条实际高度 |

## B 档：中等工程（每项半天左右）

### B1. 迷你条左右滑动切歌

- **做出来什么样**：手指在迷你条上左滑下一首、右滑上一首，不用去点小按钮，口袋里盲操都行。
- **参考**：Apple iOS 26.1 新增的手势 + Spotify 都有，切歌瞬间配轻触觉确认。
- **怎么改**：迷你条 Row 加 `detectHorizontalDragGestures`，滑过阈值调切歌。

### B2. 播放条展开动画升级

- 现在展开面板用 AnimatedVisibility 默认动画，高度「啪」地突变（MainActivity.kt:1993）。换成弹性 spring（Apple 标准：damping 0.8 / stiffness 400），展开会有顺滑的物理感。队列折叠区的 chevron 旋转已经做了（2050），风格对齐即可。

### B3. 专辑页/播放列表页补标题

- 发现页有「发现」、全部音乐有「你的音乐」，但专辑页/播放列表页直接铺网格没标题（1201/1370），五个列表页层级不统一。Spotify 的粗黑大标题就是滚动时的扫视锚点。各加一行标题行。

### B4. 空态/加载态打磨

- 专辑详情/播放列表详情加载时是裸居中转圈（1342/1677），和网格页精心做的骨架屏割裂——复用骨架思路做详情页骨架
- 空态现在是纯灰字（290），加个音乐图标 + 行动引导（如「去 QQ 下载找歌」）
- 骨架屏可加 shimmer 脉动（现在是静态灰块）

### B5. 硬编码颜色随主题修复

- 卡片白描边 `Color(0x33FFFFFF)` 重复 6 处（1117/1173/1234/1287/1402/1457），深色主题下过亮刺眼
- 封面底部黑渐变 `Color(0x08000000)`（2215）深色下几乎不可见
- 菜单白色高光描边（995）深色下过亮
- 统一换成随深浅主题切换的语义色。（原「顺带把零引用的 `PulsarDimensions` 令牌用起来」已作废：该文件全仓库零引用，已整体删除；玻璃参数现集中在 `ui/components/LiquidGlass.kt`）

## C 档：大工程（核心体验升级，分两期）

### C1. 全屏播放页 ⭐ 头号建议

**做出来什么样**：点迷你条，从底部滑出一个沉浸大页：大封面（约屏宽 90% 正方形）+ 歌名/艺人 + 进度条 + 播放控制行（中间播放键 68dp 大圆，两侧切歌，角落模式小图标）+ 下滑收起。背景就是已经做好的封面取色渐变——**这个页面的地基已经打完了**。

**参考**：

- Apple Music 垂直分区原则：信息 → 微操（进度/音量）→ 粗操（切歌）→ 模式（歌词/队列），拇指越靠近底部越是高频操作；歌名与艺人同字号，只靠字重 + 颜色分层，避免「艺人名被压小」的廉价感
- Spotify 控制按钮三级尺寸：播放键 68dp / 切歌 40dp / 模式键 28dp，视觉重量与操作频率严格对应
- 封面取色背景：Spotify 顶部 40-50% 屏高是取色高饱和版本，向下渐隐到深底色，文字恒定白字（对比度实测约 10.9:1）；Apple 教训——取色必须做亮度钳制（深色下 HSL 的 L 压到 20-35%），否则白封面夜间会「闪光弹」

**分两期**：

- 一期：纯布局 + 底部滑入/下滑收起手势（复用现有取色背景、队列逻辑、BackHandler 返回栈）
- 二期：迷你条封面到全屏大封面的 morph 共享元素动画（Compose `SharedTransitionLayout` 的教科书用例）、左右滑切换歌词/队列页（Apple 三面板 Pager 模式）

**为什么值得**：这是两大标杆共同的核心场景，也是现有 UI 唯一称得上「缺失」而不是「待打磨」的东西。

## 不建议做的（避坑）

- **Material You 壁纸取色**：已经做了封面取色，再叠壁纸取色两套动态色会打架，主题色一致性反而被破坏
- **往卡片/菜单上铺玻璃**：Apple 的明确原则是「玻璃只用于导航层」。现在只用在两根条上恰恰是对的，别扩散
- **彩色文字**：Apple 2015 版黄字红底的教训——背景可以取彩，文字永远只允许纯黑/纯白两色，否则喧宾夺主且发糊

---

## 推荐顺序

1. **先做 A 档 A1 + A2 + A3**（一次性把「感知层」补齐，半天搞定）
2. **然后开工 C 档全屏播放页一期**
3. B 档穿插着做，A4/A5/A6 任何空闲时间都能塞进去
